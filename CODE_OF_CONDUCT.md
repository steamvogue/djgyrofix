# Code of conduct

## The short version

Be decent. Assume the other person is trying to help.

## What is expected

- Keep discussion on the technical substance. Critique the code, the approach or
  the reasoning, not the person.
- Take correction well and give it kindly. Being wrong in public is how this
  work gets done.
- Accept that "no" is a legitimate answer to a feature request, and that a
  maintainer's time is finite.

## What is not

Harassment, personal attacks, demeaning comments, sustained disruption, or
publishing someone's private information. Persisting after being asked to stop
counts on its own.

## Enforcement

Report a problem to the maintainer through GitHub — open an issue if it can be
public, or use a private security advisory if it cannot.

Reports are handled discreetly. Responses run from a private word through to
removal of comments, and to blocking from the repository for anything sustained
or severe. The maintainer's judgement decides, and reporters are not put on
trial for reporting.

## Scope

The repository, its issues, pull requests and discussions.
